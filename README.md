## 🚀 Kurulum

### Gereksinimler

- .NET 9 SDK
- Microsoft SQL Server
- Visual Studio 2022 veya üzeri

### 1. Repoyu klonlayın

```bash
git clone <REPOSITORY_URL>
cd MYAcademy_PortfolioProject
```

### 2. Veritabanı bağlantısını düzenleyin

`appsettings.json` dosyası veya `PortfolioContext` içerisindeki bağlantı ayarını kendi SQL Server ortamınıza göre düzenleyin.

### 3. NuGet paketlerini yükleyin

```bash
dotnet restore
```

### 4. Veritabanını oluşturun

Projede mevcut migration dosyalarını kullanarak:

```bash
dotnet ef database update
```

### 5. Projeyi çalıştırın

```bash
dotnet run
```

Uygulama, terminalde belirtilen localhost adresinde çalışacaktır.
